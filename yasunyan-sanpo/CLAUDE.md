# やすにゃんこんにゃん！散歩チュウ（yasunyan-sanpo）

**共通ルールは号口リポジトリ `Chikuwa1014/chikugames` の `CLAUDE.md` に準拠する。** ここにはこのゲームだけの事実を書く。
このファイルは、開発を始めるときの **指示書** を兼ねる（2026-10-25 開発者が仕様を許可。仕様は付録）。

## 1. 概要

やすにゃんが、こんにゃんをリードで連れておでん横丁を散歩する、横スクロールのゲーム。道に落ちている激うまアイテムを拾いながら横丁を一周し、ゴールで集めたぶんだけこんにゃんが育って、コンカフェ嬢に変身する。1 回の散歩で完結する（1 プレイ 2〜3 分）。
現在：`β0.1.1`（2026-10-25）。β0.1.0 は最初の版。β0.1.1 で結果の表記を「スコアランク」に直した。

## 2. URL

- `/yasunyan-sanpo/`（β版リポジトリ `chikugames-beta`）
- 公開の状態：**開発に公開**（2026-10-25。`cards.js` に `dev: true`、order 105。版 β0.1.1）。URL は会話の中でだけ共有する。
  - やすにゃんは実在の人物がモチーフなので、次の段階は **限定公開（鍵付き）**。進めるのは開発者の指示があってから（号口 `CLAUDE.md` 3 章）。

## 3. コードの地図

`index.html` の 1 ファイルにまとめている（`<script>` の中を上から順に）。

| 場所 | 役割 |
|---|---|
| `CFG` | 調整用の数値（5 章） |
| `ITEMS` / `KINDS` / `TIER_LABEL` | アイテムの定義（名前・段階・点数）。段階は `normal`・`rare`・`super`・`bad` |
| `RANKS` / `COSTUMES` / `RANK_ORDER` / `charsOf()` | ランクとキャラ ID の対応・衣装 6 種。S は `RANKS.A` のキャラを使う |
| `loadSave()` / `writeSave()` / `chk()` | 保存（4 章） |
| `Snd` | 効果音と BGM（Web Audio で自作。`tone`・`noise`・`sched`） |
| `PLAYER_SPR` / `KON_SPR` / `makeSprite()` | やすにゃん・こんにゃんのドット絵（文字の絵を canvas に描いて使う） |
| `ICON` / `drawIcon()` | アイテムの絵（canvas のパスで描く） |
| `STY` / `drawScene()`（`drawFar`・`drawMid`・`drawNear`・`drawGround`） | 4 区間の背景（屋台通り・商店街・公園・神社）。区間の境目で色が混ざる。最後の帰り道は屋台通りの見た目 |
| `genWorld()` | 1 周のアイテム・障害物を毎回ランダムに並べる（区間ごとに数が決まっている） |
| `startRun()` / `playUpdate()` | 走り出しと毎フレームの更新（ジャンプ・拾う・ぶつかる・区間の切りかわり） |
| `pickItem()` / `hitObs()` | アイテムを拾う／障害物にぶつかったとき |
| `startGoal()` / `goalUpdate()` / `drawGoalFx()` / `showResult()` | ゴールの演出（食べる → 光る → 変身 → 結果）。ランクとキャラ・衣装はここで決める |
| `drawPlayer()` / `drawKon()` / `drawItems()` / `drawObs()` / `drawHud()` | 描画 |
| `openZukan()` / `buildZukan()` / `openShare()` / `openModal()` | 図鑑・共有・ダイアログ |
| `img/concafe/<キャラ>-<衣装>.png` | コンカフェ嬢の仮の絵（240×420。42 枚）。`dev/concafe_sprites.py` で作る。**あとで絵だけ差しかえられるよう、ゲームは画像ファイルとして読み込む**（絵をコードに埋め込まない）。読み込むのはゴールで決まった 1 枚と、図鑑で出たものだけ |
| `dev/concafe_sprites.py` | 上の絵を作るスクリプト。`PEOPLE`（キャラ 7 人：`a1` `a2` `b1` `b2` `c1` `d1` `d2`）・`RANKS`（ランクとキャラの対応）・`COSTUMES`（衣装 6 種：`maid` `gothic` `police` `marine` `idol` `pirate`） |
| `dev/concafe-sheet.png` | 42 枚の一覧（公開しない） |
| `dev/test.py` | 動作テスト（6 章） |

## 4. 保存キー

- `yasunyan-sanpo-v1`：`{ v, best, plays, seen }` を JSON → base64 にして、チェック値（FNV-1a、塩はゲーム名）を `.` でつなぐ（号口 `CLAUDE.md` 9 章）。チェック値が合わないときは初期化する。
  - `best`：ベスト記録（ポイント）、`plays`：さんぽした回数。
  - `seen`：図鑑。キーは `<ランク>:<キャラ>:<衣装>`（例 `D:d2:pirate`）、値は出た回数。
  - 形を変えたら、キーのバージョンを上げるか移行処理を書く。
- `yasunyan-sanpo-mute`：おと OFF のとき `1`（改ざんされても困らないので素のまま）。

## 5. 調整用の数値

`index.html` の先頭の `CFG`：歩く速さ（`speed`）、ジャンプ（`gravity`・`jumpV`・長押し `holdGravity`/`holdMax`）、区間の長さ（`sectionLen`）、ぶつかったときの `hitLoss`・`slowRate`・`slowTime`・`invuln`、ランクの境目（`rank`）、S の確率（`sChance`）、出現数（`nNormalCluster`・`nRare`・`nNanami`・`nKarashi`・`nBomb`・`obsWeights`）。アイテムの点数は `ITEMS`、超レアの高さ（長押しでしか届かない）は `genWorld()` の `y: 225`。

現在の値（2026-10-25 開発者が確認）：

- ふつう 10 点（約 40 個）、レア 30 点（12 個）、超レア 100 点（3 個）、全部取ると 1060 点。
- 減点：七味とうがらし −10（8 個）、和からし −60（4 個）、ばくだん −150（1〜2 個）。合計点は 0 未満にならない。
- ランクの境目：D 0〜299 / C 300〜499 / B 500〜699 / A 700 以上。S は A のうち 10%。
- 障害物 28 個。ぶつかると −20 点、1.5 秒遅くなる（むてき 1.2 秒）。
- 1 周は約 19000px、歩く速さ 130px/秒で、止まらなければ約 2 分半。

## 6. テスト

- `python3 yasunyan-sanpo/dev/test.py`：Playwright で、タイトル → 各区間 → ゴール（D〜S の結果）→ 図鑑 → 共有 → ボットで最後まで、をスマホ幅と PC 幅で撮る（`dev/shots/` に出る。公開しない・commit しない）。`quick` を付けるとタイトルと区間だけ。β リポジトリのルートで実行する（`../common/v1/` を読むため）。
- `python3 yasunyan-sanpo/dev/concafe_sprites.py`：コンカフェ嬢の絵を作り直す。
- ブラウザのテストでは Google Fonts が読み込めない（想定どおり。代わりの書体になる）。

## 7. ゲーム固有の決まり

- **やすにゃん**：実在の人物がモチーフ（本人の許可あり）。写真をもとにデフォルメしたドット絵にする。写真は開発者から受け取る。受け取るまでは仮のドット絵で作る（β0.1.0 は仮の絵）。**写真そのものはリポジトリに入れない**（β版のリポジトリは公開されている）。
- **こんにゃん**：ちくわゲームズのおでん横丁のキャラ（ねこ耳のこんにゃく）。見た目は号口の `stage-kobo/index.html` の「こんにゃん」の描き方を参考にする。
- **コンカフェ嬢**：コンカフェらしい衣装だが健全にする（性的な表現はしない）。大人の見た目。こんにゃんのなごりで、ねこ耳がある。
- **ランク**：S・A・B・C・D の 5 つ（良い順）。コードと文書には、ランクの記号と、キャラの ID（`a1` など）だけを書く。**ランクごとの見た目の説明は、コード・コメント・文書に書かない。**
- **表記（2026-10-25 開発者が確認）**：ランクの記号（S〜D）は内部設計の呼び名。**画面では、ポイントで決まるものを「スコアランク」と書く**（結果画面は「スコアランク：○」）。「ランク」とだけ書くと、嬢のランクに見えるため。
- **嬢のレアリティ名**（開発者が決定）：S＝芸能人、A＝有名人、B＝アイドル、C＝クラスのマドンナ、D＝一般人。コードでは `RARITY`。いまは図鑑の見出しに使っている（結果画面には出していない。未実装タスクに【保留】）。
- **S ランク**：専用のキャラは作らない（リポジトリにも入れない）。当面は **A ランクのキャラにキラキラのエフェクトを足して** S として出す。
- 絵は Claude がコードで描いた仮の絵。あとで絵師の絵などに差しかえる想定。

## 付録：仕様（2026-10-25 開発者が許可）

### 遊び方

- 横スクロール。やすにゃんは自動で右へ歩く。こんにゃんはリードでつながって、うしろをついてくる。
- **タップでジャンプ**（長押しで高く跳ぶ）。PC はスペースキーかクリック。
- アイテムは触れると拾う。
- 横丁を一周して 1 プレイ（2〜3 分）。4 つの区間：**屋台通り → 商店街 → 公園 → 神社 → スタートに戻る**。区間ごとに背景を変える。
- 障害物：水たまり・自転車・カラスなど。**ぶつかると拾ったアイテムを少し落として、少しの間足が遅くなる。ゲームオーバーはない。**

### 激うまアイテム（2026-10-25 開発者が確認）

- おでん横丁にちなんだ食べ物。**ふつう・レア・超レア**の 3 段階で、ポイントが違う。
  - ふつう（10 点）：ちくわ・だいこん・こんにゃく・はんぺん
  - レア（30 点）：たまご・牛すじ・もち巾着
  - 超レア（100 点）：金のちくわ・とろとろ味噌串
- **減点アイテム**：七味とうがらし −10、和からし −60、ばくだん −150。触れると減点（合計は 0 未満にならない）。ジャンプでよけられる。足は遅くならない。ばくだんだけ爆発の演出とゆれを付ける。

### ゴールとコンカフェ嬢

- ゴールすると、集めたアイテムをこんにゃんが食べて育ち、コンカフェ嬢に変身する演出を見せる。
- **1 周で集めたポイントで D〜A のランクが決まる。A の点数を超えたうえで、まれに S になる。**
- キャラはランクに対応する中からランダム（`RANKS`）。D は `d1`・`d2` のどちらか。
- 衣装は 6 種からランダム。
- S は当面、A のキャラ＋キラキラのエフェクト（7 章）。
- 結果画面：ポイント・ランク・コンカフェ嬢の絵。ベスト記録と、出たランク・キャラ・衣装を保存する（図鑑）。

### そのほか

- 共通部品 `common/v1/` の `core.js`（保存）と `share.js`（SNS 共有）を使う。共有の文面は `#やすにゃん散歩チュウ #ちくわげーむず`。
- 効果音・BGM は Web Audio で自作（既存の曲は使わない）。
- スマホ縦向き優先（幅 360〜400px）。PC でも遊べること。
- 画面の左上に「← ちくわゲームズ」。

### 確認済みのこと（2026-10-25）

- アイテム名・点数・ランクの境目・S の確率は、5 章の値で開発者が確認した（はんぺんと減点アイテムは開発者の追加）。
- やすにゃんの写真はまだ。仮の絵で進めてよい（開発者が確認）。
