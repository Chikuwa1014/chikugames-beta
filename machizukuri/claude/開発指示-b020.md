### 1.1 地形は平らのまま

- **土地の中（±120m）は y = 0 の平らな地面のままにする。** 建築・当たり・ねらい・見本は y = 0 を前提にしている。モックの `hAt`（1224 行）の起伏は土地の中では使わない。
- 起伏は柵の外だけに付ける。**126m から外側でなめらかに上がりはじめ**、遠景の山なみ（`buildMountains`。半径 300〜1200m）へつなぐ。柵のすぐ外（120〜126m）は y = 0。
- 土地の中の見た目の変化は、写真の混ぜ合わせと色むら（`groundTint`）と草でつける。頂点の高さは変えない。

### 1.2 マスの塗り分けの表（道・畑・踏み固め）

- 120×120 の `RawTexture`（RGBA、線形補間。1 画素が 1 マス）を作る。R＝土の道、G＝畑、B＝建物のまわりの踏み固め（建物のマスと、そのまわり 1 マスを 0.5）。
- `GroundPlugin` はこの表を世界の座標から読み、ノイズで境目をくずして `path_col`（道・踏み固め）と `farm_*`（畑）を塗る。モックの頂点の属性 `gA`・`gB`（1279 行）の代わりになる。
- 建てる・こわすたびに `MZ.gfx.ground.mark(建物)` で表の該当マスだけ書きかえて `update` する。草（`grass.js`）も同じときに、そのマスの株を消す・もどす。
- 土の道 `road` は、どの画質でもメッシュを置かず、この表で描く（「低」も同じ）。見本だけは平たい板で出す。

- **配置を変えない。** `W.buildNodes` の乱数の呼び方・回数は 1 つも変えない（変えると保存の番号がずれる）。見た目にだけ使う乱数は、別の種（`hash(idx, 種類)`）から取る。今の `VARIANTS`（`tree`・`tree2`）を引く `rng()` も、呼ぶ回数を変えないために残す。
- **LOD の並べ直し**（モックの `layoutTrees`、1907 行の考え方）：種類と LOD の段ごとに、数がその種類の全部の数の固定の入れ物（`Float32Array`）を作り、**入れ物は差しかえずに中身だけ書きかえて `thinInstanceCount` を変える**（差しかえると WebGL の警告が出る）。並べ直すのは、主人公が 4m 動いたとき、物が消えた・また出たとき、画質を変えたときだけ（0.25 秒に 1 回まで）。距離の区切りは画質の表で決める（高：木の LOD0 は 55m、LOD1 は 150m、その先はコードの木。中：22m と 90m）。
- 物ごとに「いまどの入れ物の何番目にいるか」（`nd.look = { mesh 群, slot }`）を持つ。消す・ゆらすときはそこだけ書いて `thinInstanceBufferUpdated`。
- **ゆれ**：たたいたら 0.25 秒、根もとを中心に 2〜3 度かたむけてもどす（木は上ほど大きく、岩は 1cm 横にずらす）。行列を毎フレーム書くのは、ゆれている物だけ。
- **木を切ったあと**：切った木の場所に、高・中では `stump`（大きさ 0.6〜0.8）を出し、また生えたら消す。当たりの円は木のまま（`r`）。低では何も出さない（今のまま）。
- **飾り**（採れない・当たりなし）：倒木 `deadlog` を 12 本、枯れ枝 `twigs` を 40、小石を 1800（高）／900（中）／300（低）置く。種は別の値（`T.seed + 77`）にする。小屋のまわり 6m・採れる物のマスには置かない。建物を置いたマスの飾りは消す（並べ直す）。
- 葉の材質は `allowShaderHotSwapping = false` にする（モック 953 行の注意と同じ理由）。葉のゆれは `TreeWind` のプラグイン（1876 行）。
- PBR の材質はすべて `maxSimultaneousLights = 4` にする（太陽・半球・たき火 1・予備）。

## 4. 建物・人・道具の受け皿（`js/gfx/looks.js`）

### 4.1 受け皿の決まり

- `MZ.gfx.look(種類)` は `{ src: 'glb' | 'code', lod: [{ meshes, dist }], ... }` を返す。GLB が `assets/models/b_<種類>.glb`（近く用）と `b_<種類>_far.glb`（遠く用）にあれば、それを使う。無い・読めないときは `MZ.getModel(種類)`（今のコードの形）を使う。**モデルは 1 つずつ足せる**（ファイルを置き、`MANIFEST` に 1 行足すだけ）。
- 置き方：`MZ.gfx.put` は種類ごと・部品ごとに `createInstance` する。LOD は `addLODLevel(距離, 遠く用のメッシュ)` と `addLODLevel(見える距離, null)` で付ける（インスタンスにも LOD が効く）。遠く用が無いときは、今のコードの形を遠く用にする。
- 読み込んだメッシュは、モックの `loadModelFile` と同じく `setParent(null)`・`bakeCurrentTransformIntoVertices()`・`setEnabled(false)` で元にしておく。足もとの高さを確かめ、y の最小が 0 からずれていたら直してお知らせを出す（開発中だけ console.warn）。
- 見本（緑と赤）：`look` の遠く用の部品を複製し、材質を今の `pvOk`・`pvBad` に置きかえ、`renderingGroupId = 1` にする。影には入れない。土の道の見本は 2m の平たい板。
- 当たりは今までどおりマスの表（`solid`）。モデルに当たりの形は要らない。
- 影：建物・木・岩・作業台は影を落とし、受ける。草・飾りの小石・見本は影を落とさない。
- 画質「低」は遠く用のファイルだけを読み、LOD0 を使わない。遠く用が無ければコードの形にする。
- 主人公は部品（脚・腕）を動かすので、GLB のノード名 `legL`・`legR`・`armL`・`armR` を探して今の `metadata.parts` と同じに並べる。住民は部品ごとの thin instance にし、60 人分の行列を毎フレーム書く（使い回しの入れ物）。手持ちの道具は一人称だけで、カメラの子にする。

## 5. 画質（`js/gfx/quality.js`）

- 高・中・低の 3 段階。保存キーは `machizukuri-gfx`（`'high'`・`'mid'`・`'low'`・`'auto'`、無ければ `'auto'`）。読み書きは `CG.ls`。
- 自動で決める初期値：WebGL2 が使えなければ低。タッチの端末（`pointer: coarse`）なら中。それ以外は高。自動のときだけ、遊びはじめて 10 秒の平均が 20fps より低ければ 1 段下げ、「画質を下げました（設定で変えられます）」と 1 回だけお知らせする。
- 画質の表（モックの `QUALITY` の値を基準にする）：

| 項目 | 高 | 中 | 低（β0.1.0 に近い軽さ） |
|---|---|---|---|
| 描く大きさ | 1/min(dpr, 2) | 1/min(dpr, 1.25) | 1/min(dpr, 1) |
| 影 | 3 段のカスケード・2048・110m | 2 段・1024・70m | なし |
| 後処理 | ブルーム・FXAA・MSAA 4・SSAO2・光の筋・粒子感・色ずれ | ブルーム・FXAA・粒子感 | 色の調整（トーンマッピング）だけ。パイプラインは作らない |
| 草（株） | 21000（55m で消える） | 8000（40m） | 2200（28m） |
| 写真の質感 | 色・法線・ORM（1024） | 色 1024・法線 512 | 色 512 のみ |
| モデル | 全部 | 岩・木・切り株・作業台・建物 | 読まない（建物の遠く用だけ） |
| 三角形の上限 | 170 万 | 90 万 | 30 万 |

- **低は必ず動くこと。** WebGL1 でも、GLB がひとつも読めなくても、β0.1.0 と同じに遊べること。
- 三角形の配分（高／中）：地面・遠景・空 20 万／12 万、草 60 万／24 万、木 45 万／25 万、採れる物と飾り 20 万／12 万、建物 15 万／10 万、主人公と住民（60 人）10 万／7 万。住民は 12m より近い人だけを近く用にし、建物は 25m より近い物だけを近く用にする。
- 予算を守る仕組み：`MZ.gfx.tris()`（モックの `countTris`。thin instance の数を掛ける）を 2 秒ごとに数え、上限を超えたら草の数を 10% ずつ減らす（上限の 85% を下回ったら、もとの数まで少しずつもどす）。
- 画質を変えたら、資産の読み込み → 材質の貼りかえ → 採れる物と飾りの並べ直し → 建物の置き直し（`MZ.gfx.put` をし直す）→ 影の作り直しの順に行い、ゲームの状態は触らない。

## 6. 画面（UI は今のまま）

- 画質のボタンは 2 か所に置く。上のバーの「視点」の右に「画質：高」（押すたびに高→中→低→自動。自動のときは「画質：自動（中）」）。パネルの下の「さいしょから」の左にも同じものを置く。
- 読み込み中の表示：タイトル画面はすぐに出す（3D の準備より前）。題名の下に細い進み具合の棒と「準備中 12／20」を出し、そのあいだ「はじめる」「つづきから」は押せない。**必須**（空の表・地面の写真・草）がそろうか、8 秒たったら押せるようにする。残り（木・岩・建物の GLB）は裏で読み続け、届いた組から並べ直して入れかえる（ゲームは止めない）。1 ファイルの待ち時間の上限は 20 秒。読めなかった組はコードの形のままにして、パネルの下に小さく「一部の絵を読み込めませんでした」と出す。
- 3D が使えない端末では、今と同じお知らせを出す。
