# ちくわでるでる！ドーパミン

号口の `CLAUDE.md`（共通ルール）に従う。ここにはこのゲームだけの事実を書く。

## 1. 概要
手軽でテンポよく、気持ちいいミニゲーム集。β0.2.0（2026-11-03）。4つを連続で遊ぶアーケードと、描き直した麻雀牌（SVG）が入った。入っているミニゲームは 4 つ（Chikuwa1014 の指定）：
1. 麻雀 あと1手：14 枚から 1 枚切り、次のツモであがれる形にする（45 秒）
2. 777揃え：確変中、ランプが光った順に STOP を押すと 777（60 秒・ハズレ 3 回で終わり）
3. 空き缶プレス：缶をタップで集め、プレス機でまとめてつぶす（35 秒。びんは触ると減点）
4. ゴミ箱スロー：ゲージが緑の所でタップして、丸めたゴミをゴミ箱へ（はずれ 3 回で終わり）

## 2. URL
`/chikuwa-dopamine/`。公開の状態：開発に公開（`cards.js` に `dev: true`）。URL は会話の中でだけ共有する。

## 3. コードの地図（`index.html` 1 ファイル）
| 名前 | 役割 |
|---|---|
| `SFX` / `tone` / `noise` | 効果音（WebAudio で作る。音のファイルはない） |
| `burst` / `fountain` / `floatText` / `flash` / `shake` | 演出（画面全体の `#fx` キャンバスに粒・文字） |
| `H`・`play` / `finish` / `toMenu` | 共通の進行（スコア・コンボ・時間のバー・結果画面・ベスト） |
| `MJ` | 麻雀。`gen(round)` が問題を作る（あがり形 14 枚から 1 枚抜き、余計な 1 枚を足す）。`isWin` はあがり判定（4 面子 1 雀頭。七対子は見ない） |
| `SLOT` | 777揃え。`roundStart` でランプの順番、5 回目からは赤ランプ＝逆の順番が混ざる |
| `CAN` | 空き缶プレス（canvas）。`CAP` がプレス機の容量、`doPress` でつぶす。得点は 缶数²×10 × コンボ |
| `THROW` | ゴミ箱スロー（canvas）。`newShot` でゴミ箱の位置・幅・風とゲージの緑の幅を決める |
| `startArcade` / `arcStage` | アーケード：`GAMES` の順に遊び、合間に幕間（`#mStage`）、最後に合計と内訳。ベストは `best.arcade` |
| `tileSvg` / `tileEl`（`MJ` の中） | 麻雀牌の絵（60×80 の SVG）。`TILE_IMG` を true にすると `img/tiles/*.png` を使う（付録） |
| `GAMES` / `renderMenu` | メニュー。ミニゲームを足すときは、同じ形のオブジェクト（`id`・`title`・`icon`・`desc`・`start(st)`・`stop()`）を作って `GAMES` に足す |
| `window.DOPA` | テスト用の公開 |

## 4. 保存キー
`chikuwa-dopamine-v1`：`{ best: { mahjong, slot, can, throw, arcade } }`（各ミニゲームのベスト点）。

## 5. 調整用の数値
- 制限時間：各ゲームの `startTimer(秒, …)`
- 麻雀：`gen` の清一色（1 色だけ）の出る回（`round >= 4`）・余計な牌が近くなる回（`round >= 2`）・正解の得点（`100 × コンボ + 残り時間 × 2`）
- 777：ランプの速さ `Math.max(170, 520 - round * 40)`・逆順の出る回（`round >= 5`）
- 空き缶：`CAP`・`spawn` のびんと金の缶の率
- ゴミ箱：`speed()`（針の速さ）・`binW`（ゴミ箱の幅）・風（`shots >= 5`）

- `node chikuwa-dopamine/dev/test-slot.cjs <保存先>`：777 の当たりとハズレ
- `node chikuwa-dopamine/dev/test-arcade.cjs <保存先>`：アーケードの流れ（4 つ→結果→もう一回）と、牌 34 枚の一覧のスクリーンショット

## 7. ゲーム固有の決まり
- 1 回のプレイは 1 分以内で終わるようにする（テンポ重視）。
- 当たりは必ず「音・粒・文字・ふるえ（`navigator.vibrate`）」をそろえて気持ちよくする。

## 付録：麻雀牌を画像に差し替えるとき
- 置き場所：`chikuwa-dopamine/img/tiles/`。`MJ` の中の `TILE_IMG` を `true` にする。
- 枚数とファイル名（34 枚、PNG）：萬子 `m1`〜`m9`、筒子 `p1`〜`p9`、索子 `s1`〜`s9`、字牌 `z1`〜`z7`（東・南・西・北・白・發・中の順）。例：`p5.png`。
- 大きさ：**1 枚 180×240 px**（縦横 3:4。画面では最大 56×75 px ほどで出すので、3 倍の解像度）。最小 120×160 px。
- 中身：牌の表の面だけ。牌の厚み（緑の背）と影、角の丸みは CSS で付けるので、画像には描かない（四角いまま、端まで面の色で塗る）。背景の透過はいらない。

### いまの画像（β0.2.1〜、`TILE_IMG = true`）
- Chikuwa1014 が 2026-11-03 にくれたドット絵の一覧（`dev/tiles-src.png`、1536×1024）を 34 枚に切り分け、150×190 px にそろえた（厚みと影つき。卓の緑は透明）。色数を 96 に減らして軽くした。
- 元の絵で数がまちがっていた 6 枚は、同じ絵の丸・竹を並べ直して作った：7筒・8筒・3索・6索・8索、1索（鳥の代わりに大きい竹 1 本。描き直してもらえたら差し替える）。
- 画像は厚みつきなので、CSS は `.tile.img`（背景・影なし、縦横 150:190）を使う。
