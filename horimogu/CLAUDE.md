# ほりほりもぐもぐ（horimogu）

**共通ルールは号口リポジトリ `Chikuwa1014/chikugames` の `CLAUDE.md` に準拠する。** ここにはこのゲームだけの事実を書く。

## 1. 概要

お豆腐（宙に浮いている。大きさはスモール 50³・メディアム 75³・ラージ 300³ から、プレイを始めるときにえらぶ。マルチは親がえらぶ）の中を掘り進み、鉢合わせた敵をたおす 3D バトル。床を掘り抜くと奈落のおでん鍋に沈む。
ひとりプレイ：おでん横丁のボス（まわせ！ちくわルーレットのボス 5 体）を制限時間 5 分で全滅させる。みんなで：2〜4 人。ほかのちくわ君を全滅させたら勝ち。
現在：β0.2.0（2026-10-25）。視点は「後方」（はじめ）と「近く」の 2 つ。描画は WebGL を自前で書いている（外部ライブラリなし）。

## 2. URL

- `/horimogu/`（β版リポジトリ `chikugames-beta`）
- 公開の状態：**開発に公開**（2026-10-25〜。`cards.js` は `dev: true`。URL は会話の中でだけ共有する）
- `index.html` に `noindex` を入れている。β公開のときに外すか、開発者に確認する。

## 3. コードの地図

| ファイル | 中身 |
|---|---|
| `js/tuning.js` | **調整用の数値 `HM.T`**（5 章）と `HM.VERSION` |
| `js/engine.js` | 行列 `HM.M4`、シード付き乱数 `HM.rng`・`HM.hash3`、WebGL の描画 `HM.Renderer`（ヘッドライト風の明るさと霧）、面を足す `HM.pushFace`、小さなマスでモデルを作る `HM.voxModel` |
| `js/world.js` | フィールド `HM.World(seed, spawns, size)`。大きさは試合ごと（同時に作る World は 1 つだけなので、ファイル内の `N`・`NC` を作るときに置きかえる）。マス（0 空気・1 豆腐・2 焼き豆腐・3 具）、`generate`（シード値から地形）、`carve`（掘る。何回・どの順でも結果が同じ）、`itemType`（具から出るアイテム。シード値と場所で決まる）、`raycast`、`meshChunk`（16³ のチャンクを面＋角の暗さで描く） |
| `js/models.js` | ちくわ君 `chikuwaModel(色)`、ボス `bossModel(key)`、アイテム `itemModel(種類)`、罠・弾・破片・お味噌のアーマー・おでん鍋 `potModel` |
| `js/audio.js` | 効果音 `HM.sfx`（Web Audio で作る） |
| `js/game.js` | ゲームの中身 `HM.G`。`start`・`update`・`render`。カメラ `G.camera`（`G.camMode`：`far`＝後方（最大 6 マス下がる）、`near`＝近く（3 マス）。**どちらも壁の手前で止まる**（カメラが豆腐の中に入ると、面のない豆腐の中から、まわりのトンネルが全部透けて見えるため。β0.1.1 の「手前を切り取る」方式はこれで廃止）。壁から離れると 1 秒に 6 マスまでゆっくり下がる。後方は少し上を見る（`farLookUp`）。縦長の画面は視野を広げる（`fovPortrait`）。ねらいのレイは `cam.ro`＝見ている線の上の頭のあたりから。明るさの中心は自分の頭）。自分の動き `updateMe`（段差の自動のぼり・壁で自動で掘る）、`mainAction`（掘る・なぐる）、`itemAction`。**親の仕事**：`hostOnMsg`（子からの操作）、`hostDamage`（お味噌・むてき込み）、`hostKill`、`hostCheckEnd`、`hostUpdate`（時間・罠・レーザー・敵・様子の配信）、`updateBot`（敵の AI）。**全員**：`onEvent`（親からの知らせ）、`onSnap` |
| `js/net.js` | みんなで `HM.NET`。共通部品 `room.js` のロビー、色の割り当て、`startMatch`、**親の引き継ぎ**（`beginMigration`・`hostTookOver`） |
| `js/ui.js` | 画面・HUD・レーダー・操作（スティック・見回し・ボタン・キーボード・マウス）・メインループ・結果・ひとりプレイの準備 `startSolo`。テスト用の入口 `window.__HM` |
| `index.html` | 画面（ホーム・ロビー・プレイ・一時停止・結果）と見た目 |

### しくみのメモ

- 自分の動き（位置・掘る）は自分の端末で決めてすぐ反映し、掘った分は `dig` で親へ送る。親はほかの全員へ中継する（自分の掘った分は自分へは返さない。焼き豆腐は 2 回で消えるので、2 回当てるとずれる）。
- 体力・ダメージ・弾・罠・アイテムの取り合い・敵・勝ち負けは親が決める（`hostEmit` で全員へ。親自身にも `onEvent` で届く）。ひとりプレイは自分が親（通信なし）。
- 地形はシード値から全員同じものを作る。具（アイテム）は 2×2×2 で座標が偶数。どのマスを掘っても同じ具のキーになる。
- **親の引き継ぎ**：親は 15 回／秒の `snap` に `succ`（引き継ぎ役＝入った順でつながっている子のいちばん前。生きている人を優先）を入れて配る。親が抜けたら、引き継ぎ役は `room.takeOver(code)` で同じ部屋コードの親になり、ほかの子は 1.2 秒後に `room.rejoin(code)` でつなぎ直す。抜けた親は負け（`left`）。`T.multi.rejoinWait` 秒以内に戻らない人も負け。引き継ぎの間に掘った分は `G.digLog` に記録し、戻ってきた人へ送る。つなぎ直しの間に送れなかった操作は `NET.queue` にためて、つながったら送る。
- 子が抜けたら、その子は負け（親の `onMembers`）。
- 試合中に新しく入ってきた人には `busy` を返す（次の試合から参加）。

## 4. 保存キー

- `horimogu-color`：選んだ色（`auto`・`normal`・`blue`…）
- `horimogu-name`：みんなでの名前（共通のロビー）
- `horimogu-sens`：見回す速さ
- `horimogu-cam`：視点（`far`＝後方・`near`＝近く）
- `horimogu-mute`：`'1'` ならミュート
- `horimogu-size`：選んだフィールドの大きさ（`small`・`medium`・`large`）
- `horimogu-best-v2`：`{ small, medium, large }` ごとに `{ left, at }`（ひとりで全滅させたときの残り時間のベスト）。旧 `horimogu-best-v1` はラージへ引き継ぐ

## 5. 調整用の数値

`js/tuning.js` の `HM.T`：フィールドの大きさ・見える距離、後方視点（`cam`：下がる距離・高さ・見上げる量・視野）、フィールドの大きさ（`sizes`）。小さいフィールドでは、地形の数を体積に合わせて減らし（`World.generate`）、スタート地点・敵の距離（`startSolo`）・マルチのスポーンの円（`NET.startMatch`）・レーダーの距離（`G.radarRange`）を縮める、地形の生成（`gen`：ほら穴・空洞・焼き豆腐・具の数）、ちくわ君（体力 100・速さ・ジャンプ）、掘る（半径・届く距離・間隔）、素手（ダメージ 4）、**アイテム 9 種（`items`。しらたき・ごぼうバットの値もここ）**、アイテムの出やすさ（`itemWeights`）、レーダーの距離、ひとりプレイ（5 分・ボス 5 体・出る距離）、ボスの体力・速さ・攻撃（`bosses`）、みんなで（4 人・スポーンの円・送る回数・戻りを待つ秒数）、色 8 種。

## 6. テスト

リポジトリ直下で `node horimogu/dev/server.mjs &`（β版の `worker/index.js` を Node で動かす）のあと：

- `python3 horimogu/dev/test-solo.py [出力先]`：スマホ幅・PC 幅で、ホーム → ひとりプレイ → 歩いて掘る → アイテム 9 種 → 敵にダメージ → お味噌 → からし地雷を自分で踏む → 全滅で勝ち・時間切れ・おでん鍋で負け。スクリーンショットを出す。
- `python3 horimogu/dev/test-multi.py [出力先]`：親＋子 2 人。色（自分で選んだ色・おまかせ）、位置と地形の同期、出汁ピストルのダメージを親が配る、**親が抜けて引き継ぎ**（抜けた親は負け・試合は続く・引き継ぎ後も同期）、さいごの 1 人で勝ち、ロビーへ戻って再スタート。
- ヘッドレス Chromium は `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader` で WebGL が動く（とても遅いので、ボタンは 350ms 以上押す）。

## 7. ゲーム固有の決まり

- 敵はおでん横丁のキャラ（まわせ！ちくわルーレットのボス：大根大将・がんも番長・きんちゃく姫・マグマすじ将軍・おでん大王）。
- ちくわ君の色は、最初はノーマル・青・赤・紫（入った順）。自分で変えられる（8 色）。
- セリフ：出汁ピストル「あっつい！」、お味噌「癒着！」「おみそOFF！」、ビッグ味玉「ｱｯﾂｩｲ」。
- からし地雷・しらたきは自分も踏む。
- 素手のダメージ（4）は開発者の指定がないので仮の値。
- **共通部品 `common/v1/room.js` に `takeOver`・`rejoin`（親の引き継ぎ）を足した（2026-10-25。足すだけで、ほかのゲームのふるまいは変わらない）。** いまはβ版の `common/` だけにある。号口へ昇格するときに、号口の `common/v1/room.js` にも同じ変更を入れる。
