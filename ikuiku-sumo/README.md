# いくいく！雲紅亭珍光〜すもう編〜

色のバーに合わせてボタンを押して、シコを踏みながらママのもとへ向かうリズムすもうゲーム。

- 版数：β0.3.3（β版・限定公開（鍵付き））
- 画面：ゲーム開始（タイトル）画面 →「ゲームスタート」→ プレイ画面。タイトルの音声は開始画面で流れる
- あそびかた：上から流れる色のバーが線に来たら、同じ色のボタンを押す（キーボードは A S D / J K L / 1 2 3）
- 判定：押し出し！（大きく進む）・はっけい！（小さく進む）・お漏らし💦（進まず塩をまく）
- 声（タイトル・ママに到着・頬キス・トイレの叫び・トイレのBGM）は `voice/` に入っている
- 難易度は4種：イージー＝4つ打ち／ノーマル＝8つ打ち／ハード・ベリーハード＝8つ打ちでバーが速く落ちてくる（難しいほどミスで漏らしやすい）。ベリーハードは同時押しと、押し続ける長いバーもある。バーは拍の格子に乗り、薄い横線のガイドラインで拍が見える。タイトル画面で選ぶ
- プレイ中のBGMは20曲（クラシック・ポップ・ハードロック・ハードメタル・EDM を4曲ずつ）。タイトル画面で曲かジャンルを選ぶか、ランダム。音源ファイルなし、ゲームの中で生成し、ノーツと同じ拍に合わせる
- ママに着いたら「ママ！」→成功のカット（肩を組んで、ママが頬に勝利のキス）。お漏らしの割合が増えすぎると、画面の左端からトイレへダッシュしてゲームオーバー

詳しい仕様と調整値は `CLAUDE.md`。
