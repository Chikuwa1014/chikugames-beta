# いくいく！雲紅亭珍光〜すもう編〜（ikuiku-sumo）

**共通ルールは号口リポジトリ `Chikuwa1014/chikugames` の `CLAUDE.md` に準拠する。** ここにはこのゲームだけの事実を書く。

## 1. 概要

3 色のボタンでリズムを合わせ、キャップをかぶったお相撲さん（雲紅亭珍光）がシコを踏みながらママのもとへ進む、リズムすもうゲーム。
上から落ちる色のバーを判定線で押す。判定は「押し出し！（大きく進む）／はっけい！（小さく進む）／お漏らし💦（進まず塩をまく）」。ママに着けば「ママ！」とさけび、成功のカット（ママと肩を組み、ママが頬に勝利のキス。健全なごほうび）、お漏らしの割合が上限を超えるとトイレへ駆け込むカットでゲームオーバー。
現在：β0.3.0（2026-10-25）。難易度 4 種（4つ打ち・8つ打ち・16打ち・32打ち）と、生成BGM 20 曲（5 ジャンル×4 曲）を追加。ゲーム開始（タイトル）画面で難易度と曲を選ぶ。吹き込みの声 5 つを `voice/` に入れた。プレイ中のBGMは音源ファイルなしでゲームの中で生成する。お相撲さんは、モデルの写真をデフォルメしたドット絵（黒いキャップ・丸メガネ・笑顔・チョコチップ迷彩のまわし）。

## 2. URL

- `/ikuiku-sumo/`（β版リポジトリ `chikugames-beta`）
- 公開の状態：**開発に公開**（トップのカードはぼかし・リンクなし）。URL は会話の中でだけ共有する。
- `index.html` に `noindex` を入れている。β公開（ぼかしを外す）のときに外すか、開発者に確認する。

## 3. コードの地図（`index.html` 1 ファイル）

| 場所 | 役割 |
|---|---|
| `CFG` | 難しさ・進み方の調整値（5 章） |
| `LINES` / `VOICE` | 成功・トイレのセリフと、吹き込み音声のファイルパス（空なら鳴らない） |
| `LANES` / `JUDGE` | 3 レーン（あか・みどり・あお）の色・キー、判定の文字と色 |
| `#titleScreen` / `showTitle` / `speakTitle` / `drawTitleArt` | ゲーム開始（タイトル）画面。プレイ画面（`#gameScreen`）とは別の画面で、「ゲームスタート」で `startGame()` が切りかえる。タイトルの音声はここで流す（自動再生がブロックされたら、画面の最初のタップで鳴る。スタートを押した時点でまだなら、そこで鳴らす）。絵は土俵でシコを踏むお相撲さんと手をふるママ |
| `S`（`fresh()`） | 1 プレイ分の状態。`mode`：`title`・`count`・`play`・`success`・`toilet` |
| `DIFFS` | 難易度 4 種。`sub`＝1 拍を何分割してバーを置くか（1・2・4・8）、`prob`＝格子点にバーが出る確率、`step`＝進む距離の倍率 |
| `pref` / `pickSong` / `buildTitleOptions` | 難易度・曲の選択（`ikuiku-sumo-pref-v1` に保存）。曲は 1 曲指定・ジャンル内ランダム・全曲ランダム（前回と同じ曲は避ける） |
| `genNotes` | ノーツの生成。格子は `S.grid = 60/BPM/sub`（曲の BPM に連動）。同じレーンは `CFG.LANE_GAP` 秒以内に置かない |
| `press(lane)` / `judge(kind)` | 押したときの判定と、進行・お漏らしの加算。ノーツが無いのに押してもお漏らし |
| `SONGS` / `KIT` / `KINDS` | BGM 20 曲の定義（`g`＝ジャンル、`bpm`、`ch`＝1 小節ごとのコード、`mel`＝メロディ「音名:16分音符の数」、`lead`・`comp`・`bass`・`kit`・`duck`）、ドラムのパターン、音色 |
| `makeSynth` / `BGM` | 1 曲ぶんの音を作る（16 分音符のシーケンサ。ドラム・ベース・コード・メロディ。ギターの歪み・EDM のポンピング・やわらかいリミッタ付き）。`BGM` が曲の BPM でノーツと同じ拍の頭にそろえ、`S.t0` から数える。終了時に `BGM.stop()`。`renderSong` はテスト用のオフライン再生 |
| `CUT` / `drawCut` | 成功のカットの長さと絵（2 倍の大きさ）。音声（頬キス）はカットの始まりで `playVoice('kiss')` |
| `checkEnd` / `endSuccess` / `endToilet` | 終了判定。お漏らしの割合は `leakRatio()` |
| `drawBg`・`drawSumo`・`drawMama`・`drawToilet` | シーンのドット絵（120×120 のドットを 3 倍で 360×360）。**お相撲さんのドット絵はここ（β0.1.1 でモデルの特徴を反映）** |
| `drawLane` | 落ちてくるバーと判定の文字 |
| `sfx` / `playVoice` | Web Audio の効果音／吹き込み音声 |
| `window.__IKU` | テスト用の入口（`dev/test.py` が使う） |

## 4. 保存キー

- `ikuiku-sumo-best-v2`：`{ easy, normal, hard, vhard }`（難易度ごとのベスト押し出し数）。旧 `-v1`（`{ perfect }`）はノーマルへ引き継ぐ
- `ikuiku-sumo-pref-v1`：`{ diff, song }`（選んだ難易度と曲。`song` は `'rand'`・`'g0'`〜`'g4'`・曲の番号）
- `ikuiku-sumo-mute`：`'1'` ならミュート
- 形を変えたらキーのバージョンを上げる。

## 5. 調整用の数値

`index.html` 先頭の `CFG`：`TRAVEL`（落ちる秒数）・`WIN_PERFECT` / `WIN_GOOD` / `WIN_BAD`（判定の幅）・`LANE_GAP`・`STEP_PERFECT` / `STEP_GOOD`（進む距離）・`GOAL`・`LEAK_LIMIT`（お漏らしの上限割合）・`LEAK_MIN`（割合の判定を始める回数）。難易度ごとの出やすさ・進み方は `DIFFS`（`prob`・`step`）。BPM は曲ごと（`SONGS[].bpm`）。

## 6. テスト

`python3 ikuiku-sumo/dev/test.py [スクリーンショットの出力先]`（リポジトリ直下で実行。Playwright）。20 曲すべてをオフラインで鳴らして無音・音割れ・小節数のずれが無いこと／難易度 4 種でバーが拍の格子に乗ること／ベリーハードを完璧に押して成功になること／ノーマルで成功、何もしないでトイレ→ゲームオーバーになることを確かめ、スマホ幅と PC 幅のスクリーンショットを出す。

## 7. ゲーム固有の決まり

- **ママの名前は公表しない。** ゲーム内・カード・文書（公開リポジトリ）のどこにも書かず、「ママ」とだけ書く。
- お相撲さんは実在の人物をモデルにしている（本人の許可済み）。β0.1.1 で、写真の特徴（黒いキャップ・丸い黒縁メガネ・短い黒髪・笑顔・がっしり体型・チョコチップ迷彩）をドット絵にした（360×360 の枠で表示）。写真そのものはリポジトリに入れない。
- 吹き込みの音声は 5 つ。`VOICE` のパスで鳴る（空にすると鳴らない）。ファイルは `ikuiku-sumo/voice/`：`title.wav`・`mama.wav`・`kiss.wav`・`toilet.wav`（モノラル 24kHz）、`toilet-bgm.m4a`（約 14 秒。カットの終わりの約 4.2 秒でフェードアウトして止める）。「ままぁ〜」が言い終わるまで待つため、到着からカットまで `CUT.DELAY` = 1.8 秒。`title`＝ゲーム開始（タイトル）画面を開いたとき／`mama`＝ママに到着した瞬間（ふきだし「ママ！」と同時）／`kiss`＝頬キスのカットの始まり（セリフ「どすこい申し上げます」は**ふきだしに出さない**）／`toilet`＝トイレへ駆け込む叫び声／`toiletBgm`＝トイレのカットの間だけ流れるBGM。収録し直すときは、claude.ai のアーティファクト「雲紅亭珍光 ボイス収録」で ZIP を作り、同じ名前で `voice/` に置き換える。
- プレイ中のBGMは吹き込みではなく、Claude が `SONGS` で用意した 20 曲。クラシック 4 曲（歓喜の歌・トルコ行進曲・運命・カノン）は著作権の切れた名曲の主題。ほかの 16 曲は曲名もメロディもこのゲームのための新作（既存曲のメロディは使わない）。
- 成功のカットは健全な表現にする（肩を組む・頬へのキスまで）。
- ゲーム名の「〜すもう編〜」は続編・シリーズ化を意識した付け方。
