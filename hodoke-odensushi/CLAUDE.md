# ほどけ！おでん串

号口の `CLAUDE.md`（共通ルール）に従う。ここにはこのゲームだけの事実を書く。

## 1. 概要
絡まったおでん串をタップで引き抜いて鍋に入れる、終わらないパズル。β0.1.0（2026-11-01）最初の試作。仕様の元：project の `game-ideas/hodoke-odensushi.md`（構想）。

## 2. URL
`/hodoke-odensushi/`。公開の状態：開発に公開（`cards.js` に `dev: true`）。URL は会話の中でだけ共有する。

## 3. コードの地図（`index.html` 1 ファイル）
| 名前 | 役割 |
|---|---|
| `mk` / `blockers(s, list)` / `solvable(list)` | 串の作成・抜けない理由の串を返す・盤面が最後まで解けるか（抜ける串を順に抜く） |
| `genOne(list, lv)` | 解ける串を 1 本足す（交差させ、結び目・太さをレベルで混ぜる） |
| `fill` / `reset` | 盤面を目標本数まで補充する（抜くたびに補充＝終わらない） |
| `pull` / `miss` | 抜く（得点・連鎖・組み合わせ）／抜けないとき（火力が減る） |
| `drawSkewer` / `itemPath` | 串と具の描画 |
| `window.HODOKE` | テスト用の公開 |

串：A＝持ち手（ここへ向かって抜ける）、B＝具のついた先。抜けない条件は 3 つ：進む先に串がある／自分より上（`z` が大きい）に重なっている／結び目つきで、どれかと交差している。

## 4. 保存キー
`hodoke-odensushi-best-v1`（ベスト点、数字の文字列）。

## 5. 調整用の数値
`index.html` の「調整用の数値」：`targetCount`（盤面の本数）・`drainRate`（火力の減る速さ）・`pThick`・`pKnot`・`FIRE_PULL`・`FIRE_MISS`・`PULLS_PER_LEVEL`・`RECIPES`（定番の組み合わせ）。

## 6. テスト
リポジトリ直下で `python3 -m http.server 8765` を起動し、`node hodoke-odensushi/dev/test.cjs`（300 回抜いても詰まらないこと・操作・エラー）。

## 7. ゲーム固有の決まり
- 盤面はいつも「最後まで解ける」ように足す。詰みは起きない。
- ヒント（1 回 3 つ）は、広告が使えるようになったらリワード広告に切りかえる候補（`CG.ad` は未使用）。
