# サイレント夜（仮）（β0.3.0・開発に公開）

一人称の3D脱出ホラー。研究施設の地下から、逃げて、隠れて、脱出をめざす。Babylon.js（`common/lib/`）で描く。仕様・コードの地図は `CLAUDE.md`。

## 更新履歴

- β0.3.0（2026-11-08）：アクションボタン（PC は Space、スマホは右の丸いボタン）。ベッド・机に乗り降りできる（背の高いロッカー・棚・培養槽には乗れない）。アクションを押したまま歩くと走る（1.7 倍）。ベッドの中にはまって動けなくなる不具合を直した。
- β0.2.1（2026-11-08）：バケツなど小さい物を調べやすくした（見えない当たりを大きく・真ん中から少しずれても選ぶ）。調べるボタンに調べる物の名前を出す。PC は E・F・マウス固定中の左クリックで調べる。
- β0.2.0（2026-11-08）：ステップ2。監禁部屋と研究室に鍵のかかった扉。鍵（バケツの底・倉庫のいちばん奥のロッカー）を見つけて扉を開ける。メモ 3 枚。持ち物の画面（🎒・I キー）でメモを読み返せる。
- β0.1.0（2026-11-08）：ステップ1。タイトル・プレイする人の選択・プロローグ。監禁部屋・研究室・廊下・倉庫・培養室を一人称で歩ける。懐中電灯・霧・影・画面の効果・当たり判定・調べる。
