# サイレント夜（仮）（kenkyujo）

ルールは号口の `CLAUDE.md`（全ゲーム共通）。ここにはこのゲームだけのことを書く。

## 1. 概要

一人称の3D脱出ホラー（サバイバルホラー×脱出ゲーム）。クリスマスの夜、キャンプで飲みすぎたがたすと雲紅亭珍光が、山の中の古い研究施設の地下で目をさます。戦わずに逃げる・隠れるだけ（あとで戦う要素を足せる作りにする）。
現在 β0.3.0（2026-11-08）。ステップ2「調べる・拾う・使う」まで。

企画とロードマップの正本は Claude Docs の「3D脱出ホラーゲーム 作り方ロードマップ」（決まったことの表）。

## 2. URL

`/kenkyujo/`。開発に公開（`cards.js` に `dev: true`）。β公開のときは限定公開（鍵付き。実在の人物モチーフのため）にする。
フォルダ名はタイトルに左右されないように「研究所」にした（タイトルは仮）。

## 3. コードの地図

| ファイル | 中身 |
|---|---|
| `index.html` | 画面（タイトル・プレイする人の選択・プロローグ・HUD）、拡大・縮小の止め方、はじめる流れ |
| `js/tuning.js` | 調整用の数値 `SY.T`、プレイする人 `SY.CHARS`、基本の能力 `SY.BASE`、装備 `SY.EQUIP`、能力の計算 `SY.stats(装備)` |
| `js/world.js` | マップ（文字）`SY.MAP`、マスの座標 `SY.cellPos`、部屋 `SY.ROOMS`・`SY.roomAt`、扉 `SY.DOORS`（マップの A〜Z と、開ける鍵）、持ち物 `SY.ITEMS`（鍵・メモの文）、拾える物の場所 `SY.PICKUPS`、調べたときの文 `SY.TEXTS` |
| `js/game.js` | Babylon の場面づくり（床・壁・扉・置いてある物・拾える物・光・影・画面の効果）、操作（キー・マウス固定・スティック）、音 `SY.audio`、調べる `interact()`（扉・拾う・バケツ・ロッカーの分かれ道）、持ち物 `give()`・`openBag()`・`openMemo()`、メインループ、`SY.begin` |
| `../common/lib/babylon/7.54.3/babylon.js` | Babylon.js 本体（`common/lib/README.md`） |

- 当たり判定：見えない箱 `player` に `ellipsoid` を付けて `moveWithCollisions` で動かす。**動かす前に `player.computeWorldMatrix(true)` を呼ぶ**（呼ばないと、同じフレームの中でぶつからないことがある）。
- 壁は `#` のマスの箱を `MergeMeshes` で 1 つにまとめている。机などは見えない `solid()` の箱で当たり判定を取る。
- 調べられる物は `metadata.kind` を持ち、`SY.TEXTS[kind]` の文が出る。特別な動き（扉・拾う・2 回目で鍵が出るなど）は `interact()` に書く。
- 謎の流れ（β0.2.0）：バケツを 2 回調べる → さびた鍵 → 監禁部屋の扉。廊下のメモ「走り書き」→ 倉庫のいちばん奥のロッカー → 研究室の鍵 → 研究室の扉。
- 「調べる」の選び方（`findAim()`）：まず画面の真ん中の物（目からの距離 `reach`＋0.6m まで）。なければ、横の距離が `T.reach` 以内で、真ん中から `T.aimAngle` 以内のいちばん真ん中に近い物（間に壁があればはずす）。床の小さい物は `hitbox()` で見えない当たりを大きく付ける。ボタンの名前は `SY.NAMES`。
- PC の調べる：E・F・マウス固定中の左クリック。
- **アクション**（PC は Space、スマホは右の丸いボタン `#bAct`）：入り口は `doAction()`（`actionDown()` から呼ぶ）。止まっているときに押すと乗る・降りる、歩いているときは押している間 走る（`G.run`。`T.run` 倍）。**あとで「走ったまま視線を向けるだけでアクション」にする場合がある（開発者の話、【保留】）ので、アクションを呼ぶ条件は `actionDown()` と `findMount()` に集めてある。**
- 乗れる物：`platform(key, x, z, 幅, 奥行, 上面の高さ, 当たりの mesh[])` で登録（いまはベッド・机。名前は `SY.CLIMB`）。乗っている間は `G.on`・`G.footY`、その物の当たりを切る（`softOff`）。端から出たら落ちる。降りるときは正面→左右→後ろの順に、マップの壁でない場所へ（`freeAt`）。物の中に入りこんでいたら外へ押し出す（はまって動けなくなる不具合の対策）。
- 持ち物とメモの画面を開いているあいだは `G.paused`（動かない・調べられない）。マウスの固定も外す。

## 4. 保存キー

| キー | 中身 |
|---|---|
| `kenkyujo-char` | 最後にえらんだプレイする人（`gatasu`・`chinko`） |
| `kenkyujo-mute` | 音を消しているか（`'1'`） |

持ち物（`G.inv`）はまだ保存しない（読み直すと最初から）。

セーブ（進み具合）はまだない。入れるときは `move.js` の欄も付ける。

## 5. 調整用の数値

`js/tuning.js` の `SY.T`（目の高さ・見回す速さ・霧・懐中電灯）と `SY.BASE`（移動速度・体力・防御・残機）。装備は `SY.EQUIP` に足すだけで `SY.stats` が計算する（速さは `speedMul` の倍率）。

## 6. テスト

手元で `python3 -m http.server` をリポジトリ直下で動かし、`/kenkyujo/` を開く。ヘッドレスの Chromium では `--use-gl=angle --use-angle=swiftshader` を付けると WebGL が動く（FPS は 2〜3 しか出ないので、動きの速さは本物の端末で見る）。

## 7. ゲーム固有の決まり

- プレイモードは「がたす」（基本）と「雲紅亭珍光」の 2 種。2 人は途中で別れて別行動になり、それぞれの行動が相手の展開を変えるマルチエンディング。
- 能力は装備で変わる（靴・服・アクセサリー・お守り。移動速度・防御・体力・残機）。初期装備はノーマル。
- 敵は研究施設で極秘に研究されていた「サイレントキメラ ちくわ君」（おでん横丁とつながりのある施設）。
- 1 回のプレイは 45〜70 分。PC とスマホの両方。
- タイトル「サイレント」は有名なホラーゲームの名前に近いので、正式に決めるときに見直す。
