# ぬか床そだて

号口の `CLAUDE.md`（共通ルール）に従う。ここにはこのゲームだけの事実を書く。

## 1. 概要
ぬか床の状態（乳酸菌・塩け・水分）を保ちながら食べ物を漬け、食べごろで取り出して売る、終わりのない育成ゲーム。β0.1.0（2026-11-08）最初の試作。β0.2.0（同日）で漬ける食べ物を 100 種に（SEIJI の指示：実際にぬか漬けで食べられている食材で）。
SEIJI は最初「Unity で作りたい」と言ったが、Claude の環境では Unity が動かせないので、ほかのゲームと同じ HTML＋JS（`index.html` 1 ファイル）で作った。

## 2. URL
`/nukadoko/`。公開の状態：開発に公開（`cards.js` に `dev: true`、2026-11-08）。URL は会話の中でだけ共有する。

## 3. 決まり
- 時間：ゲーム内 1 時間＝実時間 2.5 秒（1 日＝60 秒）。右上で ×3 の早送り。画面にダイアログが出ているあいだは止まる。
- ぬか床：乳酸菌は時間で増え（水分が多いほど速い）、かき混ぜると減る。野菜 1 本ごとに水分が増え、塩けが減る。24 時間混ぜないと白いカビ（調子が 6 割に下がる。混ぜると消える）。
- 手入れ：かき混ぜ（ぬか床を指でなぞる。移動量 `MIX_DIST` で 1 回）、塩（+12、5 円）、ぬか足し（水分−12・塩−4・乳酸菌−6、10 円）、水を抜く（水分−10、無料）。
- 漬かり具合：経過時間÷目安時間で、生っぽい（〜0.5）・浅漬け（〜0.85）・食べごろ（〜1.2）・古漬け（〜1.8）・漬かりすぎ。
- 点：タイミング（目安±15% なら 1）×（0.4＋0.6×漬けていたあいだのぬか床の調子の平均）。0.85 以上で★3、0.97 以上で【極み】。売値＝★3 の売値×点。
- レベル：★の合計が経験値。Lv n→n+1 に 6＋4×n（`XP_NEED`）。Lv3・5・7 で漬けられる数が 4・5・6 に増える。
- 食べ物：100 種（`CATS`。実もの 25・葉と茎 18・根といも 22・山菜ときのこ 10・果物 7・卵や魚ほか 18）。それぞれに食べごろの時間・形（18 種類。`drawShape`）・2 色・めずらしさ 1〜5。めずらしさ順に Lv1 で 6 種、以後 1 レベルごとに 4 種が棚に並ぶ（Lv25 で全部）。売値・仕入れ値は時間とめずらしさから計算（`vegPrice`）。棚は種類別のタブ。
- セーブ：β0.1.0 の英字の id（`kyuri` など）は読み込むときに名前の id に読みかえる（`OLD_ID`）。
- 注文：1 つずつ。指定の野菜を★2 以上で売るとボーナス。2 日たつと入れかわる。
- お金も漬けた野菜もなくなったら、おばあちゃんの仕送り（60 円）。

## 4. コードの地図（`index.html`）
| 名前 | 役割 |
|---|---|
| `tick(h)` | 時間を h 時間進める（ぬか床の変化・漬かり具合・日付・注文） |
| `mixDone` / `put` / `take` / `rate` / `comment` | 1 回混ぜた／漬ける／取り出す／点数／味のひとこと |
| `bedQ` / `meterQ` | ぬか床の調子（0〜1） |
| `draw` / `drawVeg` / `drawShape` | かめ・ぬか・カビ・食べ物の描画（canvas 360×320。漬かるほど同じ形を暗い色で重ねる） |
| `hud` / `shelf` | 上の表示・メーター・タブと棚 |
| `window.NUKA` | テスト用の公開 |

## 5. 保存キー
`nukadoko-save-v1`（全部の状態を JSON で）。

## 6. 調整用の数値
`index.html` の「調整用の数値」：`SEC_PER_HOUR`・`BAND`・`LAC_RATE`・`VEG_WATER`・`VEG_SALT`・`MOLD_HOURS`・`MIX_DIST`・`MIX_LAC`・`XP_NEED`・`START_ITEMS`・`ITEMS_PER_LV`・`CATS`（食べ物の表）・`vegPrice` など。

## 7. テスト
リポジトリ直下で `python3 -m http.server 8765` を起動し、`node nukadoko/dev/test.cjs [画像の出力先]`（100 種そろっているか・漬ける・混ぜる・取り出す・カビ・20 日分の世話でレベルが上がるか・全タブと図鑑の表示・古いセーブの読みかえ・エラー）。
