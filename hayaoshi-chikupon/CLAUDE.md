# 早押し！ちくぽん！ 引き継ぎメモ

全ゲーム共通のルールは号口（`Chikuwa1014/chikugames`）の `CLAUDE.md` を参照する。ここにはこのゲームだけのことを書く。

## 概要

ひとりで遊ぶ「反応速度はかり（いろ・おと・しんどう）」と、最大8人で遊ぶ「みんなで早押し」の2モード。
現在 **β0.1.0**（2026-10-24）。ファイルは `index.html` 1 枚（CSS・JS 込み）。

## コードの地図（`index.html` の `<script>` 内）

| 部分 | 中身 |
|---|---|
| `TUNING` | 調整用の数値（待ち時間・お手つきの下限・回答許可の打ち切り・同時押しの待ち時間） |
| `RANKS` | ひとり：平均タイムの称号 |
| `KINDS` | ひとり：合図の3種類（色・音・しんどう）の名前と説明 |
| `Sound` | 音（Web Audio）。合図の鳴りはじめの時刻を取る |
| `resolveKind` / `stimulate` | 使えない合図は「いろ」にかえる。合図を出して、見えた・鳴った時刻を取る |
| `soloStart` / `soloNext` / `soloFire` / `soloPress` / `soloFoul` / `soloFinish` | ひとりの進行 |
| `H`・`hGo` / `hOnMessage` / `hDecide` / `hJudge` | 親（出題者）の進行。押した時刻を集め、いちばん速い子を決める |
| `G`・`gOnMessage` / `gTap` / `renderGuest` | 子の受け取りと押したときの処理 |
| `enterMulti` / `syncPanels` | みんなで画面の入り口。`CG.room` の部屋を作る |

## 保存キー

- `hayaoshi-chikupon-best-v1`：ひとりのベスト記録 `{ color|sound|vibe: { avg, best, plays } }`
- `hayaoshi-chikupon-name`：みんなでの名前（ロビーの名前欄）

## 通信（みんなで）

- 仲介は `worker/index.js` の `WS_GAMES`（`hayaoshi-chikupon: 8`）。部屋コード 4 桁、最大 8 台、最初に入った端末が親。
- 親は回答許可の合図（`go`）を送るとき、いろ・おと・しんどうのどれかを決めて子に配る（「ランダム」はそのとき選ぶ）。
- 子は合図を受けたときに自分の時計で押したまでの時間を送る。親は送られた時間で順位を決める（同時押しは `grace` 分だけ待つ）。
- 子が押すより前に押すと、その問題はお休み（親が `foul` を受け取る）。

## 調整用の数値

`TUNING`（`index.html` の先頭付近）。`openTimeout`（だれも押さないときの打ち切り）、`grace`（同時押しの待ち）、`minValid`（お手つきの下限）など。

## テスト

- `dev/server.mjs`：本物の `worker/index.js` を Node で動かす手元サーバー（`node hayaoshi-chikupon/dev/server.mjs` → `http://localhost:8787/hayaoshi-chikupon/`。公開していなくても手元では開ける）
- `dev/test-solo.py`：ひとりの通しテスト（3種類・お手つき・結果・保存）
- `dev/test-multi.py`：みんなでの通しテスト（親＋子3人。お手つき・いろ／おと・回答権・○×・やり直し・打ち切り・終了・退出）

## ゲーム固有の決まり

- 合図の前に押すとお手つき。ひとりでは、その回を押し直せる（回数は減らない）。
- 「おと」は音が使えない端末では「いろ」になる。「しんどう」は振動が使えない端末では選べない。
- 「ランダム」は回答許可のたびに色・音・しんどうから1つを選ぶ。
