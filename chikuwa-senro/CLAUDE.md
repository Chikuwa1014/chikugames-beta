# つなげ！ちくわ線路（仮）

号口の `CLAUDE.md`（共通ルール）に従う。ここにはこのゲームだけの事実を書く。題名は仮。

## 1. 概要
横 8 × 縦 24 のフィールドに、線路のピースが上から降ってくる。つないで、底の駅から電車を走らせる。走った線路は消え、上のピースが落ちる。β0.1.0（2026-11-01）最初の試作。入っているのは アーケード（20 レベル）・フリー・実績。**対戦（バトル・協力）は未実装**。

## 2. URL
`/chikuwa-senro/`。公開の状態：開発に公開（`cards.js` に `dev: true`）。URL は会話の中でだけ共有する。

## 3. コードの地図（`index.html` 1 ファイル）
| 名前 | 役割 |
|---|---|
| `N,E,S,W` と `rot` | ピースは開いている辺のビット（岩は 0）。`rot` で回す |
| `planRun` | 駅の上のマスから、つながっている線路をたどって経路を求める（上まで抜ければ `topped`） |
| `depart` / `endRun` | 発車／走り終えたら線路を消して重力で落とす・お題の判定 |
| `arcade(n)` | レベル n のお題（走るマス数・カーブ数・岩の出る率・落ちる速さ） |
| `drawTrack` / `trainPos` | 線路と電車の描画 |
| `window.SENRO` | テスト用の公開 |

## 4. 保存キー
`chikuwa-senro-v1`：`{ cleared（アーケードで最後にクリアしたレベル）, free（フリーのベスト）, st, ach }`。

## 5. 調整用の数値
`index.html` の「調整用の数値」：`RUN_SPEED`・`MAX_MISS`・`fallRate`・`arcade(n)`・`STATION_COL`（駅の列）。

## 6. テスト
リポジトリ直下で `python3 -m http.server 8765` を起動し、`node chikuwa-senro/dev/test.cjs`（経路・走行・積み上げ・上まで到着）。

## 7. ゲーム固有の決まり（仮の案で進めたところ。Chikuwa1014 に確認する）
- 電車は駅から上へ出発する。発車は手動（「発車」ボタン）。
- 途切れたところで停車。アーケードはお題（走るマス数・カーブ数）を満たせばクリア、足りなければ失敗（3 回で終わり）。フリーは上まで着けないと脱線で終わり。
- 岩（線路でないピース）はレベル 8 から降ってくる。
- 走っているあいだはピースの落下が止まる。
