# つなげ！ちくわ線路（仮）

号口の `CLAUDE.md`（共通ルール）に従う。ここにはこのゲームだけの事実を書く。題名は仮。

## 1. 概要
横 8 × 縦 24 のフィールドに、線路のピースが 1 マスずつ上から降ってくる（重力あり。列ごとに下から詰まる）。
**駅（フィールドの外・底）から出て、駅にもどる**ルートをつなぐと金色に光り、発車できる。走った線路は消え、上の線路が落ちる。落ちてまたルートができたら自動でもう一度走る（連鎖）。
β0.2.0（2026-11-01）でゼロから作り直した（β0.2.1 で電車を窓・前照灯・パンタグラフ付きの形に描き直し）（β0.1.0 は「全然ダメ」で没）。入っているのは アーケード（20 レベル）・フリー・実績 13 個。**対戦（バトル・協力）は未実装**。

## 2. URL
`/chikuwa-senro/`。公開の状態：開発に公開（`cards.js` に `dev: true`）。URL は会話の中でだけ共有する。

## 3. ルール（β0.2.0 の決まり）
- ピース：まっすぐ・カーブ・十字（まっすぐ通りぬける。1 本のルートで縦と横の 2 回通れる）・岩（お邪魔。線路でない）。
- ルート：底の列から入り、つながった線路をたどって、別の列の底から出られたら完成。完成ルートは全部いっしょに走る（同時発車）。
- 発車：「発車」ボタン（完成ルートがあるときだけ光る）か、**発車時刻**（カウントダウン）で自動。時刻に完成ルートが無いと、いちばん長い途中までのルートを走って**脱線**（途中までの線路は消える）。
- 早く発車するほど点が上がる（残り時間に応じて最大 ×1.5）。
- 岩は、となり（上下左右）を電車が通ると、こわれる。
- 終わり：真ん中の列（ピースが出てくる列）が上まで埋まる＝**満線**。アーケードは脱線 3 回でも失敗。フリーは脱線 1 回で終わり。
- 電車が走っている間と、線路が落ちている間は、ピースの落下と発車時刻が止まる。

## 4. コードの地図（`index.html` 1 ファイル）
| 名前 | 役割 |
|---|---|
| `N,E,S,W`・`CURVES`・`rotM` | ピースは開いている辺のビット。`k` は種類（s/c/x/r） |
| `trace` / `findRoutes` / `longestPartial` | 底から線路をたどる／完成ルート一覧／脱線用の最長の途中ルート |
| `depart` / `startRun` / `updateRun` / `endRun` | 発車 → 走行（しっぽが通ったら消す）→ 点・岩・重力 |
| `gravity` / `updateSettle` / `resume` | 落とす演出 → 連鎖の確認 → 次へ |
| `LEVELS` / `GOAL_TEXT` / `goalVal` | アーケードのお題 |
| `paintTile` / `drawCar` / `posAlong` | 線路の絵・ちくわ電車・ルート上の位置 |
| `window.SENRO` | テスト用の公開 |

## 5. 保存キー
`chikuwa-senro-v1`：`{ cleared（アーケードでクリアした最大レベル）, best（フリーのベスト）, st（累計）, ach（実績）, snd（音）, seen }`。β0.1.0 の `free`（数）は `best` に読みかえる。

## 6. 調整用の数値
`index.html` の「調整用の数値」：落下速度 `fallOf`・発車間隔 `ttOf`・岩 `rockOf`・十字 `crossOf`・点 `routePts`（長いほど大きく伸びる）・倍率 `chainMul` `multiMul`・早発 `EARLY_MAX`・`LEVELS`。

## 7. テスト
リポジトリ直下で `python3 -m http.server 8765` を起動し、`node chikuwa-senro/dev/test.cjs`（ルート判定・十字・岩・連鎖・時刻の脱線・クリア・満線・脱線で終了・エラーなし）。
